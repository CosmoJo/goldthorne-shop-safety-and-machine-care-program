# Goldthorne Shop Safety and Machine Care Program

Machine map, operating procedures, maintenance schedules and safety list for the Goldthorne co-op wood shop (14 Goldthorne Ave, Etobicoke). Members assigned to look after a machine are its machine stewards.

Status: Draft revision 3 (November 13, 2026). Draft for review, not an approved operating safety standard.

Live page: https://cosmojo.github.io/goldthorne-shop-safety-and-machine-care-program/

On a phone, open the page and add it to your home screen:
- iPhone: open in Safari, tap Share, then Add to Home Screen.
- Android: open in Chrome, tap the three-dot menu, then Add to Home screen.
