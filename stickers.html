Machine stickers

One sticker per machine. Scanning the code opens that machine's page on the shop map, with its status first, then buttons to ask the AI Assistant about it or report a problem. Print on sticker paper or card, cut on the dashed lines, and put each one where it's easy to see from the operator's position. Where the shop number is blank, write it in. Each sticker also says what to do if the machine is unsafe, so it works without a phone. Goldthorne Shop Safety and Machine Care Program (draft for review).
